# 🚀 快速测试指南

本文档提供快速开始测试的步骤和常用测试命令。

---

## 📋 测试前准备

### 1. 添加测试管理器

将 `TestManager` 添加到项目的 AutoLoad 中：

1. 打开 **项目设置** → **AutoLoad**
2. 添加路径：`res://scripts/systems/test_manager.gd`
3. 节点名称：`TestManager`
4. 点击 **添加**

### 2. 确认调试工具可用

项目已包含以下调试工具：
- ✅ **状态调试面板** - 按 `Ctrl+S` 打开
- ✅ **标签调试面板** - 按 `Ctrl+T` 打开
- ✅ **天赋树界面** - 按 `Ctrl+L` 打开
- ✅ **属性面板** - 在 UI 中查看

## ⌨️ 快捷键测试命令

### 基础测试快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F1` | 显示帮助 | 查看所有可用命令 |
| `F2` | 测试所有技能 | 加载并验证所有技能资源 |
| `F3` | 测试所有状态 | 加载并验证所有状态资源 |
| `F4` | 测试所有属性 | 显示玩家当前所有属性值 |
| `F5` | 性能测试 | 测试资源加载性能和当前 FPS |

### 游戏内快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `P` | 添加天赋点数 | 每次按 P 添加 1 点天赋点数 |
| `B` | 打开/关闭背包 | 切换背包界面显示 |
| `Ctrl+S` | 状态调试面板 | 查看和管理实体状态 |
| `Ctrl+T` | 标签调试面板 | 查看实体标签 |
| `Ctrl+L` | 天赋树界面 | 打开天赋树 |

## 🧪 快速测试流程

### 第一步：基础功能测试（5分钟）

1. **启动游戏**
   - 确认游戏正常启动
   - 检查是否有错误日志

2. **测试移动**
   - 使用 `WASD` 移动
   - 确认移动流畅

3. **测试基础攻击**
   - 点击鼠标左键攻击
   - 确认攻击动画播放
   - 确认伤害计算

4. **测试技能释放**
   - 按数字键 `1-9` 释放技能
   - 确认技能正常释放
   - 确认资源消耗和冷却

### 第二步：系统功能测试（15分钟）

1. **按 `F2` 测试所有技能**
   - 检查控制台输出
   - 确认所有技能资源加载成功

2. **按 `F3` 测试所有状态**
   - 检查控制台输出
   - 确认所有状态资源加载成功

3. **按 `F4` 测试所有属性**
   - 查看属性值是否正确
   - 确认属性计算正确

4. **测试状态系统**
   - 使用状态调试面板（`Ctrl+S`）
   - 给玩家添加一个状态
   - 确认状态图标显示
   - 确认状态效果生效

5. **测试天赋系统**
   - 按 `P` 添加天赋点数
   - 按 `Ctrl+L` 打开天赋树
   - 学习一个天赋
   - 确认天赋效果生效

### 第三步：集成测试（20分钟）

1. **测试技能 + 属性**
   - 修改玩家属性
   - 释放技能
   - 确认伤害随属性变化

2. **测试技能 + 状态**
   - 释放能应用状态的技能
   - 确认状态正确应用
   - 确认状态效果生效

3. **测试技能 + 天赋**
   - 学习影响技能的天赋
   - 释放技能
   - 确认天赋效果生效

4. **测试战斗流程**
   - 攻击敌人
   - 确认伤害飘字显示
   - 确认敌人受击反馈
   - 确认敌人死亡处理

### 第四步：边界测试（10分钟）

1. **测试极端数值**
   - 设置生命值为 0（应该死亡）
   - 设置魔法值为 0（应该无法施法）
   - 设置属性值为负数（应该处理）

2. **测试状态边界**
   - 添加大量状态（测试性能）
   - 添加持续时间为 0 的状态（瞬时状态）
   - 添加层数达到最大值的状态

3. **测试技能边界**
   - 在冷却期间尝试释放技能（应该阻止）
   - 在资源不足时释放技能（应该阻止）
   - 在目标已死亡时释放技能（应该处理）

## 🐛 常见问题排查

### 问题：技能无法释放

**检查项：**
1. 技能是否在冷却中？
2. 资源是否充足？
3. 目标是否有效？
4. 是否有错误日志？

**解决方法：**
- 查看控制台错误信息
- 使用状态调试面板检查状态
- 使用属性面板检查资源值

### 问题：状态不生效

**检查项：**
1. 状态是否正确应用？
2. 状态持续时间是否过期？
3. 状态效果是否正确配置？
4. 目标是否有对应组件？

**解决方法：**
- 使用状态调试面板（`Ctrl+S`）查看
- 检查状态资源配置
- 查看控制台日志

### 问题：属性计算错误

**检查项：**
1. 基础属性值是否正确？
2. 属性修改器是否正确应用？
3. 属性依赖公式是否正确？
4. 是否有多个修改器冲突？

**解决方法：**
- 使用 `F4` 查看所有属性值
- 检查属性修改器配置
- 查看属性计算日志

### 问题：性能问题

**检查项：**
1. 当前 FPS 是多少？
2. 是否有大量实体？
3. 是否有未清理的资源？
4. 是否有内存泄漏？

**解决方法：**
- 使用 `F5` 进行性能测试
- 检查资源清理逻辑
- 使用 Godot 性能分析器
