# 特性验证使用指南

## 概述

特性系统支持验证和自动清理功能，确保特性配置的正确性。

## 特性互斥规则

### 单例特性（同一类型只能有一个）

以下特性在同一个技能中只能存在一个实例：

- **`ComboFeature`**：连击逻辑冲突
- **`ChannelingFeature`**：引导逻辑冲突
- **`ActiveFeature`**：主动技能流程冲突
- **`PassiveFeature`**：被动技能流程冲突
- **`CooldownFeature`**（待实现）：冷却管理冲突
- **`CostFeature`**（待实现）：消耗管理冲突

### 可能互斥的组合

以下特性组合可能产生逻辑冲突（系统会发出警告但不阻止执行）：

- **`ComboFeature` + `ChannelingFeature`**：连击需要快速切换，引导需要持续施法
- **`ProjectileFeature` + `MagicFieldFeature`**：投射物是移动的，魔法场是固定的

### 兼容的组合

以下特性可以安全组合：

- **`ActiveFeature` + `PassiveFeature`**：混合技能（学习时获得被动效果，也可以主动施放）
- **`ActiveFeature` + `ProjectileFeature`**：主动投射物技能
- **`ActiveFeature` + `ComboFeature`**：主动连击技能
- **`ActiveFeature` + `ChannelingFeature`**：主动引导技能
- **`ActiveFeature` + `MagicFieldFeature`**：主动魔法场技能

## API 使用

### 1. 验证特性配置

```gdscript
var ability = GameplayAbility.new()
ability.features = [
    ComboFeature.new(),
    ComboFeature.new()  # 重复！
]

var errors = ability.validate_features()
# errors = ["错误：特性 'ComboFeature' 只能存在一个实例，但发现了 2 个（将自动清理重复项）"]
```

### 2. 自动清理重复特性

```gdscript
var ability = GameplayAbility.new()
ability.features = [
    ComboFeature.new(),
    ComboFeature.new(),  # 重复
    ChannelingFeature.new()
]

# 自动清理重复项（保留第一个）
ability.cleanup_duplicate_features()
# 现在只有一个 ComboFeature
```

### 3. 检查特性是否存在

```gdscript
var ability = GameplayAbility.new()
ability.features = [ComboFeature.new()]

# 检查是否包含特定类型的特性
if ability.has_feature(ComboFeature):
    print("包含连击特性")

# 获取特定类型的特性
var combo_feature = ability.get_feature(ComboFeature)
if is_instance_valid(combo_feature):
    print("找到连击特性：%s" % combo_feature.feature_name)
```

### 4. 获取所有特定类型的特性

```gdscript
var ability = GameplayAbility.new()
ability.features = [
    ProjectileFeature.new(),
    ProjectileFeature.new()  # 虽然不推荐，但非单例特性可以有多个
]

# 获取所有投射物特性
var projectile_features = ability.get_features(ProjectileFeature)
print("找到 %d 个投射物特性" % projectile_features.size())
```

## 最佳实践

### 1. 在初始化时验证

```gdscript
func _init():
    # 配置特性
    features = [ComboFeature.new(), ProjectileFeature.new()]
    
    # 验证配置
    var errors = validate_features()
    if not errors.is_empty():
        for error in errors:
            push_warning("GameplayAbility: %s" % error)
    
    # 自动清理重复项
    cleanup_duplicate_features()
```

### 2. 在编辑器中使用

在 Godot 编辑器中，可以在 `_validate_property` 中调用验证：

```gdscript
func _validate_property(property: Dictionary) -> void:
    if property.name == "features":
        var errors = validate_features()
        if not errors.is_empty():
            property.hint_string = "警告：%s" % "\n".join(errors)
```

### 3. 运行时检查

在关键时机（如施放前）检查特性配置：

```gdscript
func can_cast(ability_comp: Node, target: Node, context: Variant = {}) -> bool:
    # 验证特性配置
    var errors = validate_features()
    if not errors.is_empty():
        for error in errors:
            push_warning("GameplayAbility: %s" % error)
        # 可以选择阻止施放或继续执行
    
    # 继续检查...
    return true
```

## 错误处理

### 错误级别

1. **错误**：重复的单例特性（会自动清理）
2. **警告**：可能互斥的组合（不阻止执行，但提醒设计者）

### 处理策略

- **自动清理**：对于重复的单例特性，系统会自动清理（保留第一个）
- **警告提示**：对于可能互斥的组合，系统会发出警告但不阻止执行
- **设计灵活性**：允许设计者实现特殊组合（如"引导连击"）

## 示例

### 示例 1：正确的配置

```gdscript
# 主动连击投射物技能
var ability = GameplayAbility.new()
ability.features = [
    ActiveFeature.new(),
    ComboFeature.new(),
    ProjectileFeature.new()
]

var errors = ability.validate_features()
# errors = []  # 无错误
```

### 示例 2：错误的配置（会自动修复）

```gdscript
# 错误：多个连击特性
var ability = GameplayAbility.new()
ability.features = [
    ComboFeature.new(),
    ComboFeature.new()  # 重复
]

var errors = ability.validate_features()
# errors = ["错误：特性 'ComboFeature' 只能存在一个实例，但发现了 2 个（将自动清理重复项）"]

ability.cleanup_duplicate_features()
# 现在只有一个 ComboFeature
```

### 示例 3：警告配置（允许但提醒）

```gdscript
# 警告：可能互斥的组合
var ability = GameplayAbility.new()
ability.features = [
    ComboFeature.new(),
    ChannelingFeature.new()  # 可能互斥
]

var errors = ability.validate_features()
# errors = ["警告：ComboFeature 和 ChannelingFeature 可能互斥（连击需要快速切换，引导需要持续施法），请确认设计意图"]

# 系统不会阻止执行，但会提醒设计者
```

## 总结

特性验证系统提供：

1. **自动清理**：自动移除重复的单例特性
2. **警告提示**：提醒可能互斥的组合
3. **设计灵活性**：允许特殊组合（不强制阻止）
4. **运行时检查**：在关键时机验证配置

通过使用这些功能，可以确保特性配置的正确性，同时保持设计的灵活性。
